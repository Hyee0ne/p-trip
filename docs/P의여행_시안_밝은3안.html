밝은 시안 3안

"답답하고 어둡다"의 원인을 찾아 셋 다 고쳤습니다. 세 안 모두 흰 바탕 · 밝은 사진 · 넉넉한 여백이고, 서로 다른 건 색의 온도와 카드 처리입니다.

이전 시안에서 고친 것

1. 시안 보드가 어두웠다 — 배경이 짙은 갈색이라 화면까지 어두워 보였습니다. 밝게 바꿨습니다.
2. 사진 자리가 탁했다 — 장터·골목을 짙은 갈색/자주로 깔았습니다. 실제 여행 사진은 바다·하늘·햇빛이라 밝습니다. 전부 밝은 색으로 교체했습니다.
3. 여백이 부족했다 — 섹션 간격을 34→48px, 좌우 여백을 22→26px로 넓히고 섹션당 항목을 3개에서 2개로 줄였습니다.

공통으로 지킨 것

이동 중 화면 = 고딕 · 여행기 = 명조 · 컨셉을 위한 UI를 새로 만들지 않음
