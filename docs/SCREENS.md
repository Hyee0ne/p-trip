## 0. 공통

### 0.1 글로벌 상태
| 상태 | 값 | 영향 범위 |
|---|---|---|
| 로그인 | guest / member | guest는 찜·여행기 저장 시 로그인 유도 시트 |
| 거점 | 미설정 / 설정됨(name, lat, lng) | 코스 상세 배너, 레이더 상단 칩, 핸드오프 목적지 |
| 여행(trip) | 없음 / 진행 중 / 종료 | 레이더 진입 시 trip 시작, "여행 마치기" 시 종료 |
| 데모 모드 | off / on | on이면 위치를 7번 국도 mock 주행으로 대체 (설정에서 토글) |
| **뷰 모드** | 한 곳씩 / 훑어보기 | CO-01·CO-02가 공유. **마지막 선택을 기억**한다. 기본값 = 한 곳씩.<br>⚠ 레이더(DR-*)에는 뷰 모드가 없다 — 언제나 한 곳씩 |

### 0.2 공통 컴포넌트
| 컴포넌트 | 스펙 |
|---|---|
| RouteBadge | 파란 타원(#1D4ED8) + 흰 테두리 + 흰 숫자. sm(22h)/md(26h)/lg(34h). 실제 국도 표지판 형태 유지 |
| 탭바 | 3탭: 발견(🛣️) / 레이더(📡) / 마이(👤). 레이더 화면에선 다크 배경 |
| 토스트 | 하단 중앙, 1.9초, 단문. 성공/안내 구분 없음(단일 스타일) |
| **뷰 토글** | 헤더 우측 세그먼트 2칸: [카드 아이콘 한 곳씩] / [그리드 아이콘 훑어보기]. 선택된 쪽만 라벨 노출 |
| **전면 카드(full-bleed)** | 「한 곳씩」·DR-02용. 사진이 화면을 채우고 하단 그라데이션 위에 텍스트.<br>액션은 **원형 버튼 3개**(넘기기 / 들르기 / 찜) — 주 버튼 82pt, 보조 60pt |
| **그리드 카드** | 「훑어보기」용. 2열, 사진 118~126h + 이름 + **보조설명 1줄**. 우상단 하트, 좌상단 태그(있을 때만) |
| **리스트 행** | 검색 결과·코스 목록용. 썸네일 60 + 이름 + 보조설명 1줄 + 하트. 행 사이 1px 구분선 |
| **필터 칩** | **한 줄을 넘지 않는다.** 밖에 두는 건 `오늘만` `가까운 곳` 둘뿐,<br>나머지(유형·국도 번호·검증된 곳만·사진 있는 곳)는 `[필터]` 버튼 뒤 시트. 켜진 개수만 버튼에 표시 |
| 스팟 카드(list-card) | 썸네일 52 + 제목 + 보조설명 + 우측 chevron/태그 |
| 확신도 문구 | 스팟 정보 하단 고정: "영업·개장 정보는 공공데이터 기준이에요. 방문 전 확인을 권해요" + [전화] [네이버 후기 보기] 링크 |
| 하트(찜) | 토글. on 시 토스트 "찜에 담았어요" |

### 0.3 공통 예외
- 네트워크 오류: 화면 중앙 "잠시 연결이 고르지 않아요" + 재시도 버튼. 레이더는 마지막 조회 결과 유지
- 위치 권한 거부: 레이더 진입 시 권한 안내 풀스크린(§DR-00)
- 빈 데이터: 각 화면 정의의 empty 상태 참조. **절대 목업 데이터로 채우지 않는다**

## CO-01. 홈 (발견 탭 루트) — `/`

**목적**: 오늘 떠날 이유를 준다. 랭킹이 아니라 '오늘·변화·흔적' 기준 큐레이션.

**뷰 모드 2개** (§0.1). 헤더 우측 토글로 전환하고 마지막 선택을 기억한다.

### A. 한 곳씩 (기본) — 스토리 덱
1. 헤더: P 로고 뱃지 + "P의 여행" + 우측 뷰 토글. **검색 아이콘을 두지 않는다**
   (검색 아이콘이 뷰 모드를 바꾸면 모드 전환을 검색으로 위장하는 셈 — 들어가는 문은 하나여야 한다)
2. **진행 인디케이터**: 카드 수만큼 막대. 현재 칸이 **7초에 걸쳐 차오르고**,
   다 차면 자동으로 다음 카드. 길게 누르면 멈춘다(읽는 중 넘어가지 않게)
3. **전면 카드**: 흰 알약 키커(+시의성 색 점) → 제목 27px → 한두 문장 → RouteBadge + 메타
4. 하단 액션 **2개**: [♥ 찜] [**이 길 보기 →**]

**카드 종류 3종** — 스팟만 흐르지 않는다. 큐레이션 3축이 그대로 카드가 된다:
| 종류 | 키커 예 | 주 버튼 | 탭 |
|---|---|---|---|
| 스팟 | "오늘만 · 다음 장은 5일 뒤"(red) | 이 길 보기 → CO-02 | CO-03 |
| 코스 | "지난주보다 검색 +38%"(sun) | 이 코스 보기 → CO-02 | CO-02 |
| 노선 | "아직 안 달린 길"(blue) | 이 길 보기 → CO-07 | CO-07 |

동작:
- **좌우 스와이프**로 넘긴다. 홈은 탭 루트라 iOS 뒤로가기 제스처와 겹치지 않는다
- ⚠ **넘긴 카드는 아무것도 기록하지 않는다.** 앉아서 훑어본 걸 '스쳐간 발견'에 넣으면
  이동 기록이 오염된다 — 그건 DR-02(실제로 지나침)의 몫이다
- ⚠ **원형 아이콘 3개를 쓰지 않는다.** 그건 글자를 못 읽는 상황(운전 중, DR-02)의 문법이다.
  홈에서는 읽을 수 있으니 글자가 있는 버튼을 쓴다. **길안내는 이 자리에 없다** — 아직 출발 전이다
- 다른 탭·다른 화면으로 가면 타이머가 멈춘다 (TickerMode + ModalRoute.isCurrent 이중 확인)

### B. 훑어보기
1. 헤더: 로고 + 뷰 토글
2. **검색창** — 누르면 §SR 검색 화면이 위로 덮인다
3. 필터 칩 한 줄: `오늘만` `가까운 곳` `[필터]`
4. 섹션 **"국도부터 고르기"** — RouteBadge lg 가로 레일 + "전체 51" → CO-07
   ⚠ **맨 위에 둔다.** 목적지가 아니라 '길'을 고르는 게 이 앱의 진입 문법이라
   (기획문서 CO-07) 큐레이션 그리드 밑에 파묻으면 안 된다
5. 큐레이션 3축 섹션 — 제목만 (보조라벨은 쓰지 않는다. 그 설명은 「한 곳씩」 카드가 이미 한다)
   · "오늘만 열리는 발견" · "조용히 뜨는 길" · "요즘 차들이 몰래 가는 곳"
   각 섹션 아래 **2열 그리드 카드**

인터랙션: 코스 카드 → CO-02, 스팟 카드 → CO-03, 국도 뱃지 → CO-07(해당 노선 필터)
상태:
- 4·5번 섹션은 **실데이터**로 채운다 (2026-08-26 결정 — 시드값 방침 폐기, §0.3 원칙과 정합).
  4번 = 데이터랩 검색·방문 변화율 / 5번 = 연관 관광지 유입 변화율. 파이프라인은 `fetch-datalab.ts`
  - ⚠ 두 지표 모두 **시점 2개**가 있어야 산출된다. M1 실측 스파이크에서 가능 여부 확인 후 확정
  - 변화율을 못 내는 경우: 해당 섹션을 **시드값으로 채우지 말고 통째로 숨긴다**
- 오늘 장날 없으면 "오늘만 열리는 발견" 섹션 헤더를 "이번 주에 열리는 발견"으로 대체.
- 「한 곳씩」에서 보여줄 발견이 0건 → "오늘은 조용하네요. 국도부터 골라볼까요?" + CO-07 링크

## SR. 검색 — `/search` (모달, 위로 덮음)

**목적**: 훑어보기에서 못 찾을 때만 쓰는 화면. **훑어보기와 시각적으로 확실히 구분되어야 한다.**

진입: CO-01 「훑어보기」의 검색창 탭. ← 로 빠져나옴. **다른 진입로는 없다.**

⚠ 구분 신호 3개 — 이걸 어기면 사용자가 지금 어느 화면인지 모른다:
1. **배경이 흰색** (훑어보기는 연한 틴트 배경)
2. **결과는 리스트 행** (훑어보기는 2열 그리드)
3. **헤더에 토글이 없다.** ← 와 입력창뿐이고 **탭바도 덮는다**

### 입력 전
1. 헤더: [←] + 입력창(플레이스홀더 "장날, 물회, 등대…")
2. 섹션 "최근 검색" + 우측 "지우기" — 리스트 행, 각 행에 ✕
3. 섹션 "이런 건 어때요" — 칩: 오늘 장날 / 물회 / 등대 / 캠핑장 / 해수욕장 / 전통시장
- 최근 검색 없음 → 이 섹션 자체를 그리지 않는다

### 결과
1. 헤더: [←] + 입력창(입력값 + ✕)
2. 필터 칩 한 줄 (§0.2 규칙 동일) — 검색어와 조건을 함께 쓰는 게 실제 사용 방식
3. 결과 수 라벨 + **리스트 행**
- 결과 0건 → "'{검색어}'로는 못 찾았어요" + "이런 건 어때요" 칩 노출.
  ⚠ 유사 결과를 억지로 채우지 않는다

## CO-07. 국도 선택 — `/routes`

**목적**: 목적지가 아니라 '길'을 고르는 우리 문법의 직접 표현.
그리고 진입로 ③("계획 없이 그냥 시작")에 답한다 — **"여기서 뭘 탈 수 있지?"**

> **2026-08-29 확정** — 지도 전면 + 끌어올리는 바텀시트. 시안 `docs/P의여행_시안_내주변국도.html`.
> 이전 안(번호 51개 그리드)은 "7번을 타야지"라고 이미 정한 사람에게만 쓸모가 있었다.
> **토글은 두지 않는다.** 지도 하나 위에 시트가 얹히고, 시트 높이가 곧 "내 주변 ↔ 전체"다.

레이아웃:
1. 상단바: back **만**. 제목을 두지 않는다 — 시트 헤더가 지금 보는 걸 이미 말하고 있어서
   ("여기서 탈 수 있는 길" / "국도 51선") 겹쳐 쓰면 같은 말이 두 번 나온다
2. **지도(전면)** — `kakao_map_plugin`
   - 현재 위치 마커 + 정확도 헤일로
   - 노선 폴리라인(#1D4ED8). 가까울수록 진하게(opacity 0.85 → 0.38)
   - 노선 라벨 = RouteBadge sm + 별명/거리. 탭하면 시트가 그 노선 행으로 스크롤
   - 줌 컨트롤(`zoomControl: true`, 우상단) + 내 위치 복귀 버튼
   - ⚠ **보이는 영역의 노선만 그린다** — `getBounds()`로 필터. 51개를 전부 얹지 않는다(WebView 부하)
3. **바텀시트(드래그, 3단)** — 이게 이 화면의 전부다
   | 상태 | 높이 | 내용 |
   |---|---|---|
   | 접힘 | ~30% | "여기서 탈 수 있는 길" + 지역명·개수 + 근처 노선 2~3행 + "↑ 끌어올리면 51선 전체" |
   | 중간 | ~55% | 근처 노선 전체 |
   | 펼침 | ~92% | 헤더 "국도 51선 / 남북 27 · 동서 24 · 총 14,000km" + 세그먼트(전체·남북·동서) + **내 주변** 섹션 → **그 밖의 길** 섹션 |
   - 행(높이 ≥60): RouteBadge lg + 별명 + 보조 한 줄(거리 / 시점–종점 / "오늘 장날") + chevron
     · 별명이 없으면 "N번 국도". 보조 줄을 모르면 **그 줄 자체를 그리지 않는다**
   - 두 번째 섹션 이름은 "전체"가 아니라 **"그 밖의 길"**이다.
     "전체"로 쓰면 바로 위 필터 칩의 "전체"와 한 화면에 같은 말이 두 번 나온다
   - 그 밖의 길에는 **내 주변에 이미 나온 노선을 다시 싣지 않는다** — 라벨이 곧 규칙이다
   - 남북/동서 필터는 **두 섹션에 똑같이** 건다. 한쪽만 걸면 목록이 서로 어긋난다
   - 내 주변이 비면 그 섹션 라벨을 달지 않는다 (나눌 게 없는데 나누는 시늉을 하지 않는다)
   - 주행 불가 노선(북한 구간): 뱃지 회색 + "통일을 기다리는 길" (탭하면 노선 소개만, 코스 없음)
4. 노선 탭 → 해당 노선의 구간 코스 리스트 → CO-02

상태 — **내 주변이 비면 시트를 펼친 채로 시작한다.**
접힌 헤더는 "여기서 탈 수 있는 길"이라고 말하는데 그 아래 내 주변이 아닌 51선이 깔리면
헤더가 거짓말을 한다. 그래서 비면 펼쳐서 헤더가 "국도 51선"이 되게 한다.

| 상황 | 한 줄 | 버튼 |
|---|---|---|
| 위치 측정 중 | "위치를 찾는 중이에요" | — (스피너) |
| 권한 거부 / 영구 거부 / 위치 서비스 꺼짐 | "위치를 켜면 여기서 탈 수 있는 길을 알려드려요" | "위치 켜기" → 각각 재요청·앱 설정·위치 설정 |
| 데이터를 안 가진 지역 | "아직 이 지역 길을 모아두지 못했어요" | — |
| 데이터는 있는데 근처 0개(바다·외곽) | "여긴 국도에서 좀 떨어져 있어요" | — |

- ⚠ 마지막 두 줄을 **반드시 구분한다.** 데이터가 없는 지역에 "국도에서 떨어져 있다"고 하면
  거짓말이다. 파이프라인이 전국을 채우기 전까지 대부분의 지역이 위쪽 경우다
  (리포지토리가 `NearbyResult.covered`로 구분해 돌려준다)
- 어느 경우에도 **막지 않는다.** 51선 목록은 그 아래 그대로 있다
- 위치는 **1회 측정**이다. 스트림으로 따라다니지 않는다 — 그건 내비의 문법이고
  이동 중 추적은 레이더(DR-01)에서만 한다
- 코스가 아직 없는 노선 → "이 길의 코스를 준비하고 있어요" + 찜(출시 알림 대체)

⚠ 원칙 경계:
- 이 지도는 **어디로 갈지 고르는 지도**다. 경로선·턴바이턴·ETA를 절대 올리지 않는다(원칙 1)
- **DR-01 레이더에는 지도를 넣지 않는다.** 운전 중 지도는 내비로 체감된다
- 정렬은 거리순 고정. 인기/평점 정렬 칩을 두지 않는다(원칙 3)

구현 상태 (2026-08-29):
- 시트·목록·위치·상태 분기 **구현 완료**. 위치는 geolocator 1회 측정(스트림 아님).
- 지도 자리는 카카오 키가 없으면 "지도는 준비 중이에요"만 띄운다 — **가짜 지도를 그리지 않는다.**
  키가 들어오면 `route_map.dart` 안에서만 바뀌고 화면 코드는 손대지 않는다.
- 근처 노선은 아직 **데모 구간(삼척–강릉)에 한해 손으로 적은 7·38·42번**이다.
  거리(km)는 노선 선형이 없어 계산할 수 없어 **null이고, 지어내지 않는다.**

의존:
- 카카오 앱 키(JavaScript) — 미확보
- 위치 권한(DR-00 온보딩) — 미구현
- 노선 GeoJSON(`pipeline/build-routes.ts`, M1) — 미구현
- `kakao_map_plugin` 0.4.0 실측(M0.5) — WebView 성능·폴리라인 개수 한계 확인 전
  → 지도만 M1에서 채워 넣는다. 화면 구조는 이미 이 문서대로다

## CO-02. 코스 상세 — `/course/:id`

4. **거점 배너** (§상태 3종):
   - 미설정: 점선 보라 배경, "오늘 밤 거점이 아직 없어요" / "잘 곳 하나만 정해두면, 가는 길이 자유로워져요" / 우측 "정하기 ›" → CO-06
   - 설정됨: 실선 초록 배경, "오늘 밤 거점: {name}" / "계획 끝. 이제 가는 길은 비워둬도 돼요" / "확정됨 ✓"

   - ⚠ 정렬 칩을 두지 않는다. 9개 안팎 목록에 정렬은 과하다 — 순서는 항상 '지나는 순서'

- ⚠ ETA/도착시간 표기 금지. "순수 주행 2:10"까지만 (도착 시각 아님)

## CO-03. 스팟 상세 — `/spot/:id`

**목적**: 헛걸음을 막는다. 마을·밥집·뷰포인트·문화시설·숙박·캠핑장·시장을 **전부 동급 스팟**으로 한 화면에서 다룬다.

> 기획문서의 CO-03(마을 상세)/CO-04(스팟 상세) 분리는 MVP에서 이 화면 하나로 통합한다.
> 마을 스토리는 공공데이터로 나오지 않아 사람이 써야 하므로 2차.

레이아웃(위→아래):
1. 상단바: back + 하트 + 공유
2. 히어로 사진(관광사진 GW). 없으면 유형색 플레이스홀더 + 유형 아이콘 — **사진 없다고 화면을 숨기지 않는다**
3. 타이틀: 스팟명 + 유형 칩(장터 red / 뷰 green / 밥 amber / 숙박·캠핑 violet / 문화 blue)
   보조: 주소 + RouteBadge sm + "국도에서 N분"
4. 오늘 배지(해당 시에만): "오늘 장날"(red) / "일몰 N분 전"(green) / "이번 주까지"(amber)
5. 정보 블록: 영업시간 · 전화 · 주차 · 화장실 — **데이터 있는 항목만 행을 그린다**(없는 항목은 빈 값으로 두지 않음)
6. **확신도 문구**(§0.2 고정): "영업·개장 정보는 공공데이터 기준이에요. 방문 전 확인을 권해요" + [전화] [네이버 후기 보기]
7. 섹션 "들른 차들은 다음에" (보조라벨 "이동 흔적 기준") — spot_links 상위 3~5개 스팟 카드 → CO-03 재귀 진입
8. 하단 고정: [길 안내 ↗](→HND 들르기용) + 하트

인터랙션:
- [전화] → 원탭 발신(`tel:`)
- [네이버 후기 보기] → 외부 브라우저, 스팟명+주소 검색 URL. **후기 내용을 가져오거나 저장하지 않는다**(원칙 3 — 링크만 열어줄 뿐)
- 하트 → saves(like), 토스트 "찜에 담았어요"
- 숙박·캠핑 유형이면 하단에 [예약 ↗](외부 링크) 추가 — 우리는 정보까지만

상태·예외:
- 영업정보·사진이 모두 없는 스팟: 확신도 문구를 강조 스타일로 올리고 "정보가 아직 얕은 곳이에요" 한 줄 추가.
  이런 스팟은 **레이더 카드로 뜨지 않는다**(신뢰도 게이트) — 브라우징으로만 도달
- spot_links 없음 → 7번 섹션 자체를 그리지 않는다(빈 상태 문구 없음)
- ⚠ 별점·후기 점수·방문자 수 랭킹 표기 금지(원칙 3)

## DR-02. 근접 발견 카드 (전면 카드)

**형식: 전면 카드**(§0.2). 사진이 화면을 채우고 하단 그라데이션 위에 텍스트가 얹힌다.
바텀 시트가 아니다 — 운전 중이라 정보 밀도보다 **한 눈에 읽히는 크기와 큰 터치 영역**이 우선이다.
⚠ 레이더에는 뷰 토글이 없다. 언제나 한 곳씩.

구성(아래→위로 읽힌다):
1. 상단 얇은 바: RouteBadge + "7번 국도 N km 기록 중" + 음성 토글
2. 상황 칩: 장날형 "{진출로} 진출로 N분 전 · 오늘만"(red) / 일몰형 "일몰 40분 전 · 국도에서 N분"(green) / 일반형 "근처에 있어요 · 국도에서 N분"
3. 타이틀 **33px/800**: 존재형 문구. "오늘이 마침 **북평 5일장**이에요" / "곧 **추암 촛대바위**에 해가 져요"
   — ⚠ 거리 카운트다운 문구 금지
4. 본문 1~2문장, **15.5px 이상**: 장날형은 "다음 장은 N일 뒤예요" 자동 포함. 발자국형은 "들른 차들은 다음에 {spot}로 갔어요"
5. 검증 배지: "✓ 영업정보·사진이 확인된 발견만 알려드려요" (첫 카드 1회)
6. **원형 액션 3개**: [✕ 넘기기 60pt] [들르기 82pt · 주버튼] [♥ 찜 60pt]
   — 좌우 스와이프로도 같은 동작. 운전 중 정확히 누르기 어려우므로 제스처를 함께 연다
동작: ✕/무시 → saves(passed) 적립 + 토스트 "스쳐간 발견에 담아뒀어요". 음성 on이면 헤드+타이틀 TTS 낭독, 15초 무응답 → 자동 passed.
쿨다운: 같은 유형 연속 금지, 30분 최대 2회.

## DR-05. 동승자 모드 (레이더 서브모드) — `/radar`

**목적**: 운전자가 못 보는 앞쪽 발견을 동승자가 대신 훑는다. **단말 1대 전제 — 실시간 동기화 없음.**

진입: DR-01 상단 [👥] 토글. 레이더 뷰가 카드 덱으로 전환된다(trip 로깅은 그대로 계속).

레이아웃:
1. 상단: "동승자 모드" + 안내 "앞쪽에 뭐가 있는지 대신 봐주세요" + [레이더로 돌아가기]
2. 카드 덱(스와이프): 진행 방향 앞쪽 스팟을 가까운 순으로. 카드 = 사진 + 이름 + 유형칩 + "국도에서 N분" + 한 줄
   - 좌 스와이프 = 넘기기 (**passed 적립 안 함** — 브라우징일 뿐, 스쳐간 발견과 구분)
   - 우 스와이프 = 찜 + "다음 정차지 후보" 등록
   - 탭 = CO-03
3. 하단: 후보 칩 가로 리스트(0개면 미노출)

동작:
- 조회는 DR-01보다 넓게: 반경 기본 20km, 방향 ±60°, **신뢰도 게이트 미적용**
  (§4-5 원칙 그대로 — 얕은 데이터는 알림엔 안 태우되 브라우징엔 보여준다)
- 후보 등록 시 DR-01 복귀 화면 상단에 "다음 정차지 제안: {spot}" 칩 1개 → 탭하면 HND
- ⚠ 운전자에게 소리·푸시로 알리지 않는다. 동승자가 정한 걸 운전자가 **볼 뿐**

상태·예외: 앞쪽 스팟 0건 → "이 앞은 잠시 조용해요" + [더 멀리 보기](반경 확대)

## DR-06. 백그라운드 근접 알림 (권한 유도 화면 + 알림)

**목적**: 앱을 안 켜고 달리는 사람에게도 발견이 닿게 한다(진입로 ③).
기획문서 §9-3의 **2단계 옵트인**을 그대로 따른다.

### 1단계 — 기본값
DR-00에서 받는 "앱 사용 중 허용". 레이더 화면이 떠 있을 때만 동작.
**여기까지가 기본이고, 2단계는 먼저 묻지 않는다.**

### 2단계 — DR-06a 유도 화면 (조건부 1회)
노출 조건: 레이더로 여행을 **2회 이상 마친** 유저가 DR-01 상단 [🔔]을 탭했을 때만.
온보딩·첫 진입에서는 절대 묻지 않는다(권한 피로 = 이탈).

내용: "앱을 꺼둬도 알려드릴까요?" / "달리는 동안에만 위치를 봅니다. 여행을 마치면 스스로 꺼져요."
버튼: [허용하러 가기] [지금은 괜찮아요]

### 알림 규칙
- **발신 조건**: discover_nearby 상위 1건이 **장날·일몰·기간임박** 중 하나일 때만.
  일반 스팟은 백그라운드로 내보내지 않는다 (재촉 금지 원칙 — 꺼둔 앱이 말을 걸 이유는 "오늘만" 뿐)
- **빈도**: 30분 최대 1회, 하루 최대 4회 (DR-02 화면 내 쿨다운보다 엄격)
- **문구**: DR-02의 헤드+타이틀 그대로. 탭 → 앱 열림 + 해당 카드 표시
- **자동 종료**: 이동이 40분간 없으면 백그라운드 추적 중단 + 무음 알림 "레이더를 접어뒀어요"
- MY-03 설정에서 언제든 off. off 해도 OS 권한은 건드리지 않는다

⚠ 플랫폼: Android(포그라운드 서비스) 우선. iOS "항상 허용"은 심사 정당화가 필요해
**공모전 데모는 Android 기준**으로 잡는다.

## MY-02. 자동 여행기 — `/trip/:id`

**목적**: 실패까지 포함한 하루의 서사화 + 공유 루프.

레이아웃(다크 그라데이션 배경, 카드는 라이트):
1. 헤더: "EP.{n} — {날짜}" + 제목 "{노선명}에서 생긴 일" + 서브 "오늘의 여행이 한 편의 이야기가 됐어요"
2. 여행기 카드:
   - 노선 뱃지 + 구간명 + 총 km
   - 스탯 3칸: 들른 발견 / 스쳐간 발견 / 계획에 없던 밥 (허탕 있으면 "허탕 N번" 대체 — 부정 아닌 담담 톤)
   - 타임라인: 시각 + 유형색 점 + 스팟명 + 한 줄(자동 생성 템플릿, 예: "\"오늘이 마침 장날\" 알림에 핸들을 꺾음")
   - **사진 스트립**: 위치 귀속된 사진 3~4장 + "+N" + 라벨(스팟명·시각). 캡션 "📍 사진 N장이 GPS·촬영 시각으로 경로 위에 자동 정리됐어요"
   - 푸터: "국도 수집 +Nkm · 스쳐간 곳은 찜에 남겨뒀어요"
3. 액션: [여행기 공유하기 ↗] — 캡처→공유시트, 토스트 "시작·끝 300m는 가려져요"
4. 한 줄 제안(ghost): "이 동네가 좋았다면, 하루 더? ↗" → 주변 숙박 스팟 정보 바텀시트(정보+외부 링크만)

상태: 사진 권한 없음 → 스트립 자리에 "사진 접근을 허용하면 자동으로 정리해드려요" + 설정 링크. 발견 0회 → 스탯 유지 + 타임라인에 출발·도착만, 문구 "이번엔 그냥 달린 날 — 스쳐간 N곳은 다음 핑계예요"

## MY-01/03. 마이 — `/my`

레이아웃:
1. 프로필: 아바타 + 닉네임 + "여행기 N편 · 발견 N곳"
2. 국도 수집 카드: "대한민국 국도 51선 — 지금 {n}선째" + 진행바 + "{노선}(구간) Nkm 중 Nkm 색칠 · 완주까지 Nkm"
3. 섹션 "찜 & 스쳐간 발견": 세그먼트 [찜 | 스쳐간] + 스팟 카드 리스트. empty: "아직 담긴 발견이 없어요. 레이더가 담아주거나, ❤️로 직접 담아요."
4. 섹션 "여행기": EP 리스트 → MY-02
5. 설정: 알림(푸시/음성), 데모 모드 토글, 사진 접근, 로그아웃
