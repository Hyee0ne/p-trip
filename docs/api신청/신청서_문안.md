## 서비스 설명 (짧은 버전 — 400자 내외)

**P의 여행 — 국도 위의 발견 레이더**

목적지를 정하지 않고 국도를 달리는 사람을 위한 앱입니다.
사용자는 **길과 방향만** 고르고, 앱이 달리는 동안 3~7분 앞에 무엇이 있는지 알려줍니다.

한국관광공사 국문관광정보(TourAPI)로 전국 국도 51선 회랑의 관광지·음식점·숙박·
축제 정보를 수집하고, 사진·영업시간·주소가 확인된 곳만 신뢰도 게이트(60점)를 통과시켜
운전 중 화면에 내보냅니다. 오늘 장이 서는 전통시장, 40분 뒤 해가 지는 전망대처럼
**지금 이 시각에만 의미 있는 정보**를 우선합니다.

내비게이션이 아닙니다. 턴바이턴 안내를 하지 않고, 길안내는 카카오내비·티맵·애플지도로
넘깁니다. 별점과 후기도 두지 않습니다 — 신뢰는 데이터 완성도와 이동 흔적으로만 판단합니다.

## 서비스 설명 (긴 버전)

### 무엇을 하는 서비스인가

고속도로는 빠르지만 아무것도 남지 않습니다. 국도에는 지나치기엔 아까운 것들이 있는데,
목적지를 정해 달리면 그냥 지나칩니다. 이 앱은 **목적지 대신 길을 고르는** 여행을 돕습니다.

1. 지도에서 국도를 고르고 방향(북/남 또는 동/서)을 정합니다
2. 달리기 시작하면 레이더가 현재 위치 반경 5km, 진행 방향 ±60°를 살핍니다
3. 국도에서 우회 10분 안쪽에 볼 만한 곳이 있으면 전면 카드로 한 곳씩 알립니다
4. 들르면 카카오내비로 넘기고, 지나치면 조용히 「스쳐간 발견」으로 적립합니다

### TourAPI를 어떻게 쓰는가

| 오퍼레이션 | 용도 |
|---|---|
| 지역기반 관광정보조회 | 국도 회랑 3.5km 안쪽 스팟 목록 (전국 37,922건 후보) |
| 소개정보조회 | 영업시간 — 신뢰도 배점 20점, 헛걸음을 막는 핵심 |
| 공통정보조회 | 개요 — 발견 카드 본문 |
| 이미지정보조회 | 추가사진 및 공공누리 저작권 유형 |
| 법정동코드조회 | 시도·시군구 코드 정본 |
| 연관관광지 (TarRlteTarService1) | 이동 흔적 기반 큐레이션 |

수집한 데이터는 **신뢰도 게이트**를 거칩니다 — 대표사진 35 / 추가사진 10 / 전화 15 /
영업시간 20 / 번지주소 10 / 개요 10 점, **60점 미만은 운전 중 화면에 내보내지 않습니다.**
정보가 얕은 곳으로 운전자를 보내지 않기 위해서입니다.

### 왜 운영계정이 필요한가

- 목표: 국도 51선 회랑 전역 약 **19,700곳**
- 현재: **3,341곳** 수집 완료 (게이트 통과 2,462곳)
- 개발계정 일일 1,000건 제한으로 **17일이 더 필요**합니다
- 이미 출시된 서비스라 사용자가 있는 지역부터 순차로 채우고 있습니다

### 출처 표기

앱 「마이 > 데이터 출처」 화면에 공공누리 조건에 따라 표기하고 있습니다.

> 공공데이터 출처: 한국관광공사(국문 관광정보·관광지 연관정보),
