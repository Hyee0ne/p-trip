# 「P의 여행」 데모 영상 편집 브리프

> 영상 편집 AI에게 넘기는 문서. 앱이 무엇이고, 무엇을 보여줘야 하고, 무엇을 보여주면 안 되는지.
> 2026-09-13 기준 (App Store 1.0.3 심사 중, 1.0.2 출시됨). 화면 정의 정본은 `docs/SCREENS.md`.

---

## 1. 한 줄 정의

**P의 여행** (App Store 이름 「P의여행:국도편」) — 국도 위의 우연한 발견을 설계하는 **발견 레이더** 앱.
목적지를 묻지 않는다. **길을 고르고, 방향만 정하고, 달리면** 앞쪽에 뭐가 있는지 카드 한 장으로 알려준다.

- 핵심 카피: **「지나치기엔 아까운 것들이, 길마다 있어요.」**
- 부제(스토어): 「국도 위의 발견 레이더」
- 프로모션 문장: 「목적지를 정하지 않는 여행. 국도를 고르고 방향만 정하면, 달리는 동안 앞쪽에 무엇이 있는지 알려드려요. 오늘만 서는 장, 40분 뒤의 일몰, 이름 없는 물회 골목.」
- 온보딩 부제: 「네비가 못 알려주는 길 위의 발견」

**이 앱이 아닌 것** (영상에서도 절대 그렇게 보이면 안 된다):
- 내비게이션이 아니다 — 턴바이턴·경로 재탐색·도착 예정 시각이 없다. 길안내는 티맵/애플 지도로 넘긴다.
- 숙소·예약 앱이 아니다 — 예약·결제 화면이 없다.
- 후기 앱이 아니다 — 별점·후기·랭킹이 없다. "영업정보·사진이 확인된 곳만" 알려준다.
- 계정이 없다 — 회원가입·로그인 화면이 없다. 광고도 추적도 없다.

## 2. 영상의 용도와 형식

- **1차 용도**: 2026 관광데이터 활용 공모전 심사용 데모 영상 (제출 마감 2026-09-21).
  한국관광공사 OpenAPI 등 공공데이터 활용이 심사 포인트다 → 데이터 출처가 화면에 한 번은 보여야 한다.
- 2차 용도: App Store 앱 미리보기(세로 9:16, 15~30초)로 잘라 쓸 수 있게 세로 소스를 남겨 주면 좋다.
- 길이: **60~90초** 권장 (공모전 규정이 따로 있으면 그쪽 우선).
- 화면비: 16:9 본편에 아이폰 목업(세로 화면)을 얹는 구성, 또는 9:16 풀스크린. 원본 캡처는 iPhone 17 Pro Max 1320×2868.
- 언어: 한국어 자막. 내레이션은 선택(있으면 차분한 톤, 해요체).

## 4. 화면별 설명 (무엇이 보이고, 무엇을 강조할지)

### 홈 = 지도 (발견 탭)
- Apple 지도 위에 **국도 51선이 전부 파란 선**으로 그려져 있다. 고른 길은 노란색.
- 아래 시트: 「여기서 탈 수 있는 길」 + 노선 행(파란 타원 뱃지 7 / 42 / 38). 행마다 한 줄 큐레이션:
  「오늘 이 길에 장이 3곳 서요」 「함께 찾는 곳이 많아요」 「최근에도 함께 찾는 곳이 많아요」(1.0.4부터. 1.0.3 녹화본엔 「이 길로 다녀간 사람이 많아요」).
- 끌어올리면 「국도 51선」 전체 목록. 필터는 한 줄(전체 / 남북(홀수) / 동서(짝수)).
- 강조: **목적지 검색창이 주인공이 아니다.** 지도에서 길을 짚는 장면.

### 출발 시트 (길 떠나기)
- 「7번 국도」 뱃지 → 「여기서 어느 쪽으로 갈까요?」 → [북쪽으로] [남쪽으로] 두 버튼.
- 문장: 「목적지는 정하지 않아요. 가다 마음에 들면 멈추면 돼요.」 — 이 문장은 꼭 읽히게.
- 출발하면 내비 앱 선택 시트: [티맵] [애플 지도]. 앱은 길안내를 직접 하지 않는다는 걸 자연스럽게 보여준다.

### 레이더 (다크 화면)
- 검은 배경, 동심원 레이더, 내 위치 점, 앞쪽 스팟 점(유형색: 음식 노랑·자연 초록·명소 파랑·시장 빨강).
- 좌상단 「7번 국도 4km 기록 중」, 상단 「주변을 살피는 중」 + 스피커 아이콘.
- 아래 「오늘 들른 곳」 자취(사진 원 + 점선 + 「다음」), 「오늘 여행 마치기」 버튼.
- **경로선·화살표·남은 거리·도착 시각을 절대 얹지 말 것.** 현재 위치 기준으로 주변만 본다.

### 발견 카드 (전면 카드)
- 사진이 화면을 채우는 한 장. 위에 상황 한 줄: 「오늘이 마침 북평민속오일장이에요 · 여기서 약 1.2 km」.
- 본문 예: 「3·8일에만 서는 장이라, 다음 장은 5일 뒤예요.」
- 원형 액션 3개: **넘기기 / 들르기 / 찜**. 아래 작은 글씨 「영업정보·사진이 확인된 발견만 알려드려요」.
- 「들르기」를 누르면 티맵으로 넘어간다(안내 중에도 목적지가 바뀐다). 앱은 그 자리를 「오늘 들른 곳」에 남긴다.
- 일몰 카드: 「곧 추암 촛대바위에 해가 져요」. 시간에 걸린 발견이라는 걸 보여주는 두 번째 카드.
- ⚠ 거리는 「여기서 약 N km」 직선거리다. **분·도착 시각으로 바꿔 말하지 말 것.** 줄어드는 숫자 연출 금지.

### 알림 · 소리 (티맵이 앞에 있을 때)
- 카드는 소리로 먼저 읽어주고(내비 음성을 끊지 않고 잠깐 낮춤), 놓치면 알림에 남는다.
  온보딩 문장 그대로: 「내비를 켜둔 채여도 소리로 먼저 알려드려요」 「놓쳐도 알림에 남아요. 눌러서 되돌아갈 수 있어요」.
- 알림을 누르면 그 발견의 상세로 바로 열린다. (1.0.3)

### 들른 뒤 — 「여기서 앞쪽으로」 (1.0.3)
- 밥을 먹고 차가 2분쯤 서 있으면 시트가 저절로 펼쳐진다: 앞쪽 10km 안 후보 세 곳 + 「그냥 7번 국도로 돌아가기」.
- 여행 중 다른 국도로 갈아타기: 「길을 바꿀까요?」 — 여행과 기록은 이어진다(43 → 6번 국도).

### 스팟 상세
- 관광공사 사진(워터마크 보임)·개요·영업정보·「네이버 후기 보기」 링크(내용은 안 가져온다). 별점 없음.

### 여행기 (마이 탭)
- 「EP.6 — 2026.09.13」 「43번 국도에서 생긴 일」, 지나온 길 포스터(실제 GPS 선 + 들른 곳 번호 점), 타임라인.
- 「여행기 공유하기」 → 포스터 한 장(PNG). 시작·끝 300m는 잘려 나간다(집 보호) — 굳이 말하지 않아도 된다.
- 마이: 국도 51선 중 몇 선째인지 쌓인다. 찜 목록. 설정(소리·알림·발견 간격).

## 5. 데모 시나리오 (촬영·재현 기준)

**7번 국도 삼척 → 강릉(북쪽으로).** 앱의 공식 시연 동선이다.
1. 홈에서 7번 국도(동해 바닷길) 선택 → 「북쪽으로」 출발
2. 레이더 → 장날 카드 **북평민속오일장**(3·8일장) → 들르기 → 티맵
3. 다시 달리다 일몰 카드 **추암 촛대바위** → 찜 / 또는 **어달해변**
4. 「오늘 여행 마치기」 → 여행기 → 공유 포스터

재현 방법: 테스트 빌드(TestFlight 1.0.3 9~18, DEMO_BUILD)는 설정에 **모의 주행(데모 모드)** 이 있어 차 없이 실제 선형 위를 달린다.
시뮬레이터에서는 `--dart-define=FAKE_LOCATION=37.5245,129.1143`(동해) + `START_AT=/radar` 등으로 화면을 바로 띄울 수 있다(`docs/출시_절차.md` §5-4-1).
⚠ 테스트 빌드 레이더 아래의 회색 한 줄 `DIAG 후보 … 간격 …`은 **진단용이다. 영상에 나오면 안 된다** — `--dart-define=DIAG=false` 로 끄거나 잘라낸다.

## 6. 비주얼 아이덴티티

- **아트 디렉션 「오후의 빛」** — 이 앱의 킬러 기능은 전부 시간에 걸려 있다(오늘 장날·40분 뒤 일몰·밥때·기간 한정). 그래서 **시간이 곧 배경**이다. 영상도 아침 → 낮 → 골든아워 → 밤으로 빛이 흐르면 앱과 같은 말을 한다.
- 브랜드 고정색: route blue `#1D4ED8` · field green `#3E7C4F` · market red `#C2452D` · sun `#E8A13D` · night `#0D1117` · bg `#F4F5F1`.
  골든아워 팔레트 `#F7DCAE → #E8A13D → #C2452D`, 밤 `#0D1117 / #161F2B / #243244`.
- 서체: **Pretendard 하나**(고딕). 명조·손글씨 안 쓴다. 자막도 Pretendard(또는 Noto Sans KR).
- 시그니처: **국도 표지판 파란 타원 뱃지**(숫자). 로고 대신 이걸 모티프로 써도 된다.
- 감성은 **사진·여백·문장**에서 온다. 파티클·글로우·과한 트랜지션·이모지 아이콘은 앱 톤과 어긋난다.
- 레이더만 다크, 나머지는 라이트. 홈은 지도.
- 참고 시안: `docs/P의여행_시안_오후의빛.html` (아트 디렉션), `docs/P의여행_프로토타입_v2.html` (비주얼 기준).

## 7. 톤 & 카피 규칙

- 해요체. 짧게. 재촉하지 않는다 — "지금 결정하세요" "N초 남음" 류 금지.
- 목적지·도착 시각·소요 시간을 말하지 않는다. "몇 시간 걸리는지도 묻지 않습니다."
- 별점·후기·랭킹 표현 금지. 신뢰는 "영업정보·사진이 확인된" 것과 "다녀간 사람이 많다"(이동 흔적)로만.
- 그대로 써도 되는 문장(앱 안의 실제 문구):
  - 「지나치기엔 아까운 것들이, 길마다 있어요.」
  - 「목적지는 안 정해요. 길만 골라요.」 / 「길을 고르고 · 방향만 정하고 · 달리면 됩니다」 / 「발견은 가면서 나와요」
  - 「앞쪽에 뭐가 있는지, 카드 한 장으로 알려드려요」
  - 「목적지는 정하지 않아요. 가다 마음에 들면 멈추면 돼요.」
  - 「오늘이 마침 북평민속오일장이에요」 「곧 추암 촛대바위에 해가 져요」 「다음 장은 5일 뒤예요」
  - 「영업정보·사진이 확인된 발견만 알려드려요」
  - 「오늘의 여행이 한 편의 이야기가 됐어요」
  - 「이번엔 그냥 달린 날 — 길만 남은 것도 여행이에요」 (발견 0회 여행기)
  - 스토어 설명 첫 줄: 「고속도로는 빠릅니다. 그런데 아무것도 남지 않습니다.」 / 「「P의 여행」은 목적지를 묻지 않습니다.」

## 8. 하지 말 것 (체크리스트)

- [ ] 턴바이턴 화살표·경로 하이라이트·ETA·"N분 뒤 도착" 그래픽을 만들지 않는다
- [ ] 발견 카드의 거리를 분으로 바꾸거나 줄어드는 카운트다운으로 연출하지 않는다
- [ ] 별점·후기·순위·"TOP 10" 표현을 넣지 않는다
- [ ] 예약·결제·숙소 추천 장면을 넣지 않는다
- [ ] 로그인·회원가입 장면이 없다 (실제로 없다)
- [ ] 카카오맵·카카오내비를 언급하지 않는다 (지도는 Apple, 내비는 티맵/애플 지도)
- [ ] 폐기된 기능을 말하지 않는다: 스쳐간 발견, 오늘 밤 거점, 사진 스트립, 동승자 모드
- [ ] 테스트 빌드의 `DIAG …` 진단 줄, 「모의 주행」 설정 토글이 화면에 남지 않게 한다
- [ ] 운전자가 주행 중 화면을 조작하는 장면은 피한다 — 정차 중 조작, 또는 동승자 시점으로. 소리·알림이 주행 중 채널이라는 게 이 앱의 안전 논리다
- [ ] 관광공사 사진의 워터마크를 지우지 않는다
