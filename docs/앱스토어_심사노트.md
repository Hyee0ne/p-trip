# App Store 심사 노트 (App Review Information → Notes)

> App Store Connect의 「앱 심사 정보 → 메모」에 넣을 내용.
> **백그라운드 위치가 이 앱 심사의 최대 관문**이라 그 정당화를 가장 먼저 적는다.

---

## 영문 (심사자용)

```
ABOUT THE APP
P의 여행 (P's Trip) helps drivers discover places along Korea's national
highways (국도). The user picks a road and a direction — not a destination —
and the app surfaces nearby attractions while driving.

WHY BACKGROUND LOCATION IS REQUIRED
The core value of this app is telling the driver what is 3-7 minutes AHEAD
on the road they are currently driving. This is only useful while the vehicle
is moving, and drivers keep a navigation app (Kakao Navi) in the foreground.
Without background location the app cannot know the vehicle has moved and
cannot surface a discovery before the exit is passed.

- We request "When In Use" authorization ONLY. We never request "Always".
- Background updates use UIBackgroundModes: location with
  allowsBackgroundLocationUpdates, which shows the blue status bar the entire
  time. The user always knows location is active.
- Background location is OFF by default. It is enabled only after the user
  explicitly opts in (Settings → "앱을 꺼둬도 알림"), and we never ask for it
  during onboarding.
- Tracking stops automatically after 40 minutes without movement.

WHY UIBackgroundModes: audio IS ALSO DECLARED
Discoveries are spoken aloud, not shown as banners — the user is driving and
cannot read the screen. The audio session uses .playback with mixWithOthers
and duckOthers, so it never interrupts the navigation app's voice guidance;
it briefly lowers it and restores it.

NO ACCOUNT / NO TRACKING
There is no sign-up or login. Saved places and trip logs are stored on the
device only. We do not collect names, emails, or advertising identifiers, and
we do not use any analytics SDK. Coordinates are sent to our backend only to
query nearby places and are not associated with any user identifier.

PHOTO ACCESS
Used only to build the trip journal. We read only photos taken during the time
window of that trip. Photos never leave the device.

MAPS (Guideline 4 - Design, addressed in 1.0.0 build 5)
The first submission was rejected because the app only offered third-party
navigation apps. The handoff sheet now offers Apple Maps alongside Kakao Navi
and TMAP. Tap any discovery card, then "들르기" (Stop by) to see the sheet:
[카카오내비 열기] / [티맵] [애플 지도].

We hand off to an external app rather than drawing turn-by-turn ourselves —
this app is a discovery radar, not a navigation app. Kakao Navi is listed first
because it is the only one that accepts waypoints, which lets us keep the user's
lodging as the destination while adding the discovery as a stop. TMAP and Apple
Maps receive the discovery itself as the destination, and the sheet says so.

DEMO NOTES FOR REVIEW
- Location: the app is built around Korea's national highways. Please set the
  simulator/device location to somewhere in Korea (e.g. 37.5245, 129.1143 —
  Donghae, on Route 7) to see discoveries. Outside Korea the map will load but
  no discoveries will appear.
- Data coverage is currently focused on Route 7 (Samcheok–Gangneung).
- No login is required. All screens are reachable immediately.
```

## 국문 (내부 참고)

**백그라운드 위치를 쓰는 이유**
이 앱의 핵심은 **지금 달리는 길의 3~7분 앞**에 무엇이 있는지 알려주는 것이다.
차가 움직여야만 의미가 있고, 운전자는 앞에 내비를 띄워둔다.
백그라운드 위치가 없으면 차가 움직인 걸 알 수 없어 진출로를 지나친 뒤에야 알리게 된다.

**방어 장치 (심사에서 이걸 말한다)**
- **'항상 허용'을 요구하지 않는다.** '앱을 사용하는 동안'만 받는다
- 파란 표시줄이 계속 떠 있다 — 사용자가 모르는 채로 위치를 받지 않는다
- **기본값이 꺼짐**이고, 온보딩에서 묻지 않는다. 사용자가 설정에서 직접 켜야 한다
- 40분간 이동이 없으면 스스로 멈춘다

**`audio` 배경 모드를 함께 선언한 이유**
발견을 **소리로** 알린다. 운전 중이라 배너를 읽을 수 없다.
`.playback` + `mixWithOthers` + `duckOthers`라 내비 안내를 **끊지 않고**
잠깐 작아졌다 돌아온다.

⚠ **심사자가 한국 밖에 있으면 발견이 하나도 안 뜬다.** 이 앱은 대한민국 국도가 전제다.
   심사 노트에 좌표(37.5245, 129.1143 — 동해, 7번 국도 위)를 반드시 적을 것.
   이걸 안 적으면 "앱이 동작하지 않는다"로 반려될 수 있다.
