## 서비스 설명 * (4000 bytes 이내 — 아래는 1,462 bytes)

```
국도 위의 우연한 발견을 설계하는 '발견 레이더' 모바일 앱입니다.

고속도로는 빠르지만 아무것도 남지 않습니다. 국도에는 오늘만 서는 5일장, 40분 뒤의 일몰, 이름 없는 물회 골목이 있는데 대부분 지나치고 나서야 알게 됩니다. 이 앱은 주말이 소중해 계획 없이 떠나기 어려운 사람들이, 그렇다고 정해진 코스만 따라가지는 않도록 만들었습니다.

사용 흐름은 셋입니다.
① 지도에서 탈 국도를 고릅니다. 목적지가 아니라 '길'을 고르는 것이 이 앱의 진입 방식입니다.
② 어느 쪽으로 갈지만 정하고 출발합니다. 도착지도 소요시간도 묻지 않습니다.
③ 달리는 동안 앞쪽 3~7분 거리에 무엇이 있는지 알려줍니다.

한국관광공사 국문 관광정보를 국토교통부 도로중심선 기반의 국도 51선 선형과 PostGIS로 대조하여, 국도에서 10분 이내로 닿는 관광지만 남기고 진출 지점과 우회 시간을 미리 계산합니다. 여기에 전통시장 장날, 한국천문연구원 일출·일몰과 천문현상을 겹쳐 '오늘만 볼 수 있는 것'을 가려냅니다.

공공데이터는 앱에서 직접 호출하지 않고 서버 배치로 자체 DB에 적재합니다. 주행 중 사용하는 앱이라 응답 지연이 안전 문제로 이어지고, 인증키가 앱에 포함되지 않아야 하기 때문입니다.
```

## 기능 및 서비스 화면 * (4000 bytes 이내 — 아래는 2,053 bytes)

```
[1] 지도에서 국도 고르기
현재 위치에서 탈 수 있는 국도를 지도와 목록으로 보여줍니다. 지도의 노선을 직접 눌러도 되고 목록에서 골라도 됩니다.
- 활용 데이터: 국토교통부 도로중심선(국도 51선 선형), 한국관광공사 국문 관광정보
- 노선마다 '오늘 이 길에 장이 서요' 같은 한 줄이 붙습니다. 전국전통시장표준데이터의 개설주기로 오늘이 장날인지 판정합니다.

[2] 길 떠나기
국도를 고르면 방향만 정하고 출발합니다. 현재 위치에서 그 국도까지는 카카오내비로 안내하고, 이후에는 앱이 주변을 살핍니다.
- 활용 데이터: 국토교통부 도로중심선

[3] 발견 레이더 (주행 중)
현재 위치와 진행 방향을 기준으로 앞쪽 3~7분 거리의 관광지를 카드 한 장으로 띄웁니다. 경로를 따라가지 않으므로 길을 바꿔도 그대로 동작합니다.
- 활용 데이터: 한국관광공사 국문 관광정보(위치·영업정보·개요·사진), 전통시장표준데이터, 한국천문연구원 출몰시각
- 오늘 장이 서는 시장, 일몰 40분 전의 전망 좋은 곳처럼 '지금 아니면 안 되는 것'에 가중치를 둡니다.
- 영업정보와 사진이 확인된 곳만 알립니다. 헛걸음을 줄이기 위한 것으로, 별점이나 후기는 쓰지 않습니다.

[4] 스팟 상세
관광지의 사진·개요·영업시간·전화번호를 보여줍니다.
- 활용 데이터: 한국관광공사 국문 관광정보(detailIntro2, detailCommon2, 관광사진)

[5] 자동 여행기
주행이 끝나면 들른 곳과 스쳐간 곳을 시간순으로 정리해 한 편의 기록으로 만듭니다.
- 활용 데이터: 한국천문연구원 천문현상·출몰시각 (그날 밤 달이 없었는지, 유성우가 있었는지를 한 줄로)

[6] 국도 51선 수집
지나온 GPS 좌표를 국도 선형에 대조해 노선별 주행 거리를 적립합니다.
- 활용 데이터: 국토교통부 도로중심선
```

### 첨부: 서비스 캡처 화면 (장당 10MB, 1회 30MB / JPG·GIF·PNG·BMP)

권장 4장 — 위 [1]~[5]와 짝이 맞게:

| 화면 | 무엇을 보여주나 |
|---|---|
| 홈 (지도 + 국도 목록) | 국도를 고르는 진입 방식 |
| 길 떠나기 시트 | 방향만 정하고 출발 |
| 레이더 + 발견 카드 | 주행 중 관광정보 활용 — **이게 핵심 화면이다** |
| 스팟 상세 | 관광공사 사진·개요·영업정보 활용 |

⚠ 발견 카드 화면에 관광공사 사진과 영업정보가 함께 보이는 것이 좋다 —
  공공데이터를 어떻게 쓰는지가 한 장에 드러난다.

## 참고: 활용 신청할 오픈API

| 제공기관 | 서비스명 | 용도 |
|---|---|---|
| 한국관광공사 | 국문 관광정보 서비스_GW | 관광지 정보·영업정보·개요·사진 |
| 한국관광공사 | 관광지 연관 관광지 정보 서비스 | 방문 흐름 변화 |
| 한국천문연구원 | 출몰시각 정보 | 일몰·천문박명 |
| 한국천문연구원 | 천문우주 지식정보(천문현상) | 유성우·월식 |

※ 전국전통시장표준데이터는 파일(CSV) 제공이라 API 신청 대상이 아니다.

**일일 트래픽**: 초기 전국 적재에 약 13만 콜이 필요해 **일 10,000건**을 신청한다.
정상 운영 시에는 일 500건 내외다. 수집기가 중단·재개를 전제로 짜여 있어
한도에 닿으면 멈추고 다음 날 이어받는다.

호출을 줄이려고 이미 적용한 것:
- **회랑 사전 필터** — 좌표를 국도 선형과 먼저 대조해 회랑 밖은 상세를 아예 안 부른다
  (상세는 1건당 1콜이라 이 필터가 가장 크게 줄인다)
- **선별 호출** — 개요는 신뢰도 기준 통과분에만
- **목록 캐시** — 재개할 때 목록을 다시 안 받는다
- **호출 간격 제어** — 동시 4건 + 250ms
