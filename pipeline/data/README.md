# pipeline/data/

파일로 받는 원본 데이터를 여기 둔다. **커밋하지 않는다** (.gitignore 대상).

## 전국전통시장표준데이터

- 출처: https://www.data.go.kr/data/15012894/standard.do (소상공인시장진흥공단)
- **오픈API가 없다.** 파일 제공만 한다. 갱신주기도 연 1회라 파일이 맞다.
- 받는 법: 위 페이지 → 「그리드」 탭 → CSV 내려받기
- 저장 이름: `markets.csv` (이 이름으로 둬야 파이프라인이 찾는다)
- 인코딩은 EUC-KR로 오는 경우가 많다. 파서가 자동 판별한다.

우리가 쓰는 필드: 시장명 · 시장유형 · **시장개설주기** · 위도 · 경도 · 소재지도로명주소

## 일반국도 도로중심선 (노선 선형)

- 출처: https://www.data.go.kr/data/15122482/fileData.do (국토교통부)
- 오픈API 없음. ZIP(SHP) 파일 제공.
- 받는 법: 위 페이지에서 ZIP 내려받아 **`data/roads/`** 에 풀기
  (`.shp` `.dbf` `.prj` 세 파일이 같이 있어야 한다 — `.prj`로 좌표계를 읽는다)
- `npm run build:routes`가 노선번호로 뽑아 WGS84로 변환해 `routes.geom`에 넣는다.
- ⚠ 지금은 **데모 구간(삼척–강릉)에 걸친 노선만** 넣는다. 전국은 시드가 너무 커진다.
- 없어도 앱은 돈다 — 지도에 국도 선만 안 그려진다.
